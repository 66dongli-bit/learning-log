# Learning Log

A Django web application for recording learning topics and notes.

## Features

- User registration
- User login and logout
- Add, edit and delete learning topics
- Add, edit and delete entries
- User data isolation
- Bootstrap-based UI

## Tech Stack

- Python
- Django
- SQLite
- HTML
- Bootstrap

## How to Run

Open in browser:
http://127.0.0.1:8000/

```bash
python manage.py migrate
python manage.py runserver
